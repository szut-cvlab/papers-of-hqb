## 摘要

**问题**: 视觉语言预训练（VLP）若端到端训练大规模模型，计算成本越来越高；而且端到端预训练模型难以灵活利用现成的单模态预训练模型（如图像编码器、LLM）。

**方案**: 提出 **BLIP-2**，从**冻结的预训练图像编码器**和**冻结的预训练大语言模型**出发，用轻量 **Querying Transformer（Q-Former）** 桥接模态鸿沟。Q-Former 分两阶段预训练：
1. **视觉-语言表示学习**：从冻结图像编码器学习与文本相关的视觉表示；
2. **视觉到语言生成学习**：把 Q-Former 输出接到冻结 LLM，学习生成文本。

**关键创新/贡献**：
- **创新点1（Q-Former 信息瓶颈）**: 用 32 个可学习 query 从任意分辨率图像中提取固定数量视觉特征，既压缩视觉 token，又迫使 query 只保留与文本相关的信息。
- **创新点2（两阶段预训练）**: 第一阶段用 ITC/ITG/ITM 学习表示，第二阶段用语言建模/prefix 语言建模把视觉表示接入冻结 LLM。
- **创新点3（极高参数效率）**: 可训练参数远少于端到端 VLP；零样本 VQAv2 比 Flamingo80B 高 **8.7%**，可训练参数少 **54 倍**。
- **创新点4（零样本指令生成）**: 冻结 LLM 保留指令跟随能力，可通过文本 prompt 控制图像到文本生成（视觉知识推理、常识推理、视觉对话、个性化描述等）。

**验证**:
- 零样本 VQAv2：BLIP-2（ViT-g + FlanT5-XXL）**65.0**，Flamingo80B **56.3**（Table 2）。
- 零样本图像描述：NoCaps CIDEr **121.6**、SPICE **15.8**；COCO 微调 CIDEr **145.8**（Table 3）。
- 零样本图文检索：Flickr30K TR@1 **97.6**、IR@1 **89.7**；COCO 微调 **85.4 / 68.3**（Table 5）。
- 零样本 VQA 可训练参数仅 **108M**（ViT-g + FlanT5-XXL），总参数 12.1B（Table 2）。

## 1. 引言

**背景 & 动机**:
- VLP 已成为多模态基础模型的核心，但主流方法端到端训练大规模模型，计算成本极高。
- 端到端模型不灵活：无法直接复用快速进步的视觉编码器与 LLM；每换一个骨干就要重新预训练。
- 现有模块化方法（Frozen、Flamingo）证明冻结 LLM 可行，但仍需大量图文对训练连接层，且视觉特征对齐仍是难点。

**本文思路**:
- 用轻量 Q-Former 作为冻结图像编码器与冻结 LLM 之间的**信息瓶颈**：
  - 一端用 cross-attention 从图像特征提取固定数量 query 表示；
  - 另一端把 query 表示投影为 soft visual prompt，前置到 LLM 文本输入。
- 第一阶段先学“文本相关的视觉表示”，第二阶段再学“视觉到语言生成”；这样 LLM 不必从头学视觉对齐，减少灾难性遗忘。

**贡献**:
1. Q-Former + 两阶段预训练，可高效利用任意现成视觉编码器与 LLM。
2. 零样本 VQA 比 Flamingo80B 高 8.7%，可训练参数少 54 倍。
3. 保留 LLM 的指令跟随能力，实现零样本 instructed image-to-text generation。
4. 在零样本 VQA、图像描述、图文检索上达到 SOTA，且训练成本低（16×A100 最大模型第一阶段 <6 天、第二阶段 <3 天）。

## 2. 相关工作

### 2.1 端到端视觉语言预训练

- 架构包括双编码器（CLIP、ALIGN）、融合编码器（LXMERT、ALBEF）、编码器-解码器（VL-T5、SimVLM、PaLI）、统一 Transformer（BLIP、BEiT-3）。
- 预训练目标逐渐收敛为：图文对比（ITC）、图文匹配（ITM）、（掩码）语言建模。
- 问题：模型越大，端到端预训练成本越高；且难以复用现成单模态模型。

### 2.2 模块化视觉语言预训练

- 冻结图像编码器：早期用冻结目标检测器（UNITER/OSCAR/VinVL），LiT 用冻结 CLIP 图像编码器。
- 冻结语言模型：Frozen、Flamingo、VGPPT、MAPL 等；关键挑战是**把视觉特征对齐到文本空间**。
  - Frozen 微调图像编码器，输出直接作为 LLM soft prompt；
  - Flamingo 在 LLM 中插入 cross-attention 层，用数十亿图文对训练新层。
- BLIP-2 的区别：**同时冻结图像编码器与 LLM**，用 Q-Former 做信息瓶颈，训练成本更低、性能更强。

## 3. 方法

### 3.1 Q-Former 架构

Q-Former 是 BLIP-2 唯一可训练模块（**188M** 参数），由两个共享 self-attention 的 Transformer 子模块组成：
1. **Image Transformer**：与冻结图像编码器交互，提取视觉特征；
2. **Text Transformer**：可充当文本编码器或文本解码器。

**关键设计**:
- 创建固定数量**可学习 query embeddings**（论文用 **32** 个，每个 768 维）作为 Image Transformer 输入。
- query 之间通过 self-attention 交互；通过 cross-attention 与冻结图像特征交互；cross-attention **每隔一个 Transformer block 插入**。
- query 还可通过同一组 self-attention 与文本交互；不同预训练任务使用不同 attention mask 控制 query-text 交互。
- Q-Former 用 **BERT-base** 初始化，cross-attention 层随机初始化。
- 输出 query 表示 $Z$ 尺寸为 $32\times768$，远小于冻结图像特征（如 ViT-L/14 的 $257\times1024$）。这个瓶颈迫使 query 只提取与文本最相关的视觉信息。

### 3.2 第一阶段：从冻结图像编码器学习视觉-语言表示

用图文对预训练，联合优化三个目标，共享输入格式与参数，但使用不同 attention mask：

1. **ITC（Image-Text Contrastive）**
   - 对齐 Image Transformer 的 query 输出 $Z$ 与 Text Transformer 的 `[CLS]` 表示 $t$。
   - $Z$ 有多个 query 输出，先计算每个 query 与 $t$ 的相似度，取最高作为图像-文本相似度。
   - 用**单模态 mask**，query 与文本不能互相看到，避免信息泄漏。
   - 由于图像编码器冻结，单卡可放更多样本，因此用 **in-batch negatives**，不用 BLIP 的 momentum queue。
2. **ITG（Image-grounded Text Generation）**
   - 给定图像生成文本；由于冻结图像编码器不能直接与文本 token 交互，生成所需信息必须先由 query 提取，再通过 self-attention 传给文本 token。
   - 这迫使 query 提取覆盖文本全部信息的视觉特征。
   - 用**多模态因果 mask**：query 之间可互相看，但不能看文本；每个文本 token 可看所有 query 与其之前的文本 token；首 token 用 `[DEC]` 替代 `[CLS]`。
3. **ITM（Image-Text Matching）**
   - 二分类判断图文是否匹配；用**双向 mask**，query 与文本可互相看。
   - 每个 query 输出经二分类线性层得到 logit，所有 query 的 logit 取平均作为匹配分数。
   - 用 ALBEF/BLIP 的硬负样本挖掘。

### 3.3 第二阶段：从冻结 LLM 学习视觉到语言生成

- 用全连接层把 query 输出 $Z$ 投影到 LLM 文本 embedding 维度。
- 投影后的 query embeddings **前置**到输入文本 embeddings，作为 **soft visual prompts** 条件化 LLM。
- 由于 Q-Former 已被第一阶段训练为“提取语言相关视觉信息”的信息瓶颈，LLM 只需学习如何利用这些 soft prompts，减轻视觉-语言对齐负担，缓解灾难性遗忘。

**两类 LLM**:
- **Decoder-based LLM**（OPT）：用语言建模损失，冻结 LLM 根据视觉表示生成文本。
- **Encoder-decoder LLM**（FlanT5）：用 prefix 语言建模损失，把文本切成前缀/后缀；前缀与视觉表示拼接送入 encoder，后缀作为 decoder 生成目标。

### 3.4 预训练设置

**数据**:
- 与 BLIP 相同的 **129M** 图像：COCO、Visual Genome、CC3M、CC12M、SBU、LAION400M 的 115M。
- 用 BLIP-large captioner 为每张图生成 **10 条**合成描述；用 CLIP ViT-L/14 对合成描述与原始网络描述打分，保留 **top-2**，每个预训练 step 随机选一条。

**冻结模型**:
- 图像编码器：CLIP **ViT-L/14** 或 EVA-CLIP **ViT-g/14**；去掉最后一层，用倒数第二层输出（略好）。
- LLM：OPT（decoder）或 FlanT5（encoder-decoder）。

**训练**:
- 第一阶段 250k steps，第二阶段 80k steps。
- batch size：第一阶段 ViT-L/ViT-g 为 2320/1680；第二阶段 OPT/FlanT5 为 1920/1520。
- 冻结 ViT/LLM 参数转 FP16（FlanT5 用 BF16），无性能下降。
- 最大模型 ViT-g + FlanT5-XXL 在单台 16×A100(40G) 上，第一阶段 <6 天、第二阶段 <3 天。
- AdamW，$\beta_1=0.9$、$\beta_2=0.98$，weight decay 0.05；cosine 衰减，峰值学习率 $1\times10^{-4}$，warmup 2k；第二阶段最小学习率 $5\times10^{-5}$。
- 图像 $224\times224$，随机缩放裁剪 + 水平翻转。

- 零样本 VQAv2 比 Flamingo80B 高 **8.7**（65.0 vs 56.3），可训练参数 **108M vs 10.2B（约 1/94）**；摘要用 54× 是相对 Flamingo 可训练参数的另一种口径，见 Q&A。
- OK-VQA 上低于 Flamingo80B（45.9 vs 50.6），作者归因于 Flamingo 的 70B Chinchilla 世界知识更多，而 BLIP-2 用 11B FlanT5-XXL。
- 更强图像编码器（ViT-g > ViT-L）或更强 LLM（FlanT5 > OPT、XXL > XL）都带来提升，说明 BLIP-2 是通用框架，可直接吸收单模态模型进步。

**表示学习的重要性**:
- 去掉第一阶段，只用第二阶段生成学习，零样本 VQA 大幅下降；OPT 还会出现灾难性遗忘，随训练进行性能退化。
- 第一阶段的表示学习让 Q-Former 先学会提取语言相关视觉特征，显著降低 LLM 对齐负担。

## 5. 局限

- **缺少 in-context learning**：BLIP-2 的预训练样本每条只含一个图文对，LLM 学不到多图文对序列中的相关性；给 LLM 提供 few-shot VQA 示例也没有提升。作者计划构造类似 Flamingo M3W 的交错数据。
- 图像到文本生成可能因 LLM 知识不准确、推理路径错误、缺少新信息而不理想。
- 继承冻结 LLM 的风险：有毒语言、社会偏见、隐私泄露；可用指令引导或过滤数据缓解。
- 检索/描述/ VQA 仍需任务微调，不是完全零样本通用助手。

---

## 6. 结论

BLIP-2 提出一种通用、计算高效的视觉语言预训练方法：利用冻结图像编码器与冻结 LLM，用 Q-Former 两阶段桥接模态。它在零样本 VQA、图像描述、图文检索上达到 SOTA，可训练参数远少于端到端方法；并展现零样本指令式图像到文本生成能力，是通向多模态对话智能体的一步。

## 附录 A. 实现细节

- Q-Former：188M 参数，32 queries × 768 维，BERT-base 初始化，cross-attention 每 2 个 block 插入。
- 图像编码器：CLIP ViT-L/14 或 EVA-CLIP ViT-g/14，取倒数第二层输出。
- LLM：OPT 2.7B/6.7B，FlanT5-XL/XXL。
- 第一阶段 250k steps，第二阶段 80k steps；batch 2320/1680（视觉）、1920/1520（LLM）。
- 129M 预训练图像；BLIP-large 生成 10 条描述，CLIP 排序保留 top-2。
- 16×A100 最大模型 <6 天 + <3 天。
- 微调：描述/ VQA 冻结 LLM，更新 Q-Former 与图像编码器；检索只用第一阶段模型。

## 附录 B. 更多结果与消融

- 检索消融：ITC、ITM、ITG 都对检索有贡献，ITG 提升视觉-语言对齐。
- 表示学习消融：去掉第一阶段，零样本 VQA 显著下降；OPT 出现灾难性遗忘。
- VQA 问题引导：把问题输入 Q-Former，可让 query 关注问题相关区域。
- 零样本定性：视觉知识推理、常识推理、视觉对话、个性化描述等。

## 本文涉及到的模型具体结构

| 模块 | 结构 | 说明 |
|---|---|---|
| 冻结图像编码器 | CLIP ViT-L/14 或 EVA-CLIP ViT-g/14 | 取倒数第二层特征 |
| Q-Former | 188M，32 queries × 768 | Image Transformer + Text Transformer 共享 SA；CA 每 2 block |
| 第一阶段目标 | ITC + ITG + ITM | 不同 attention mask 控制 query-text 交互 |
| 冻结 LLM | OPT（decoder）或 FlanT5（encoder-decoder） | 第二阶段接入 |
| 视觉-语言连接 | FC 投影 query → LLM 维度 | 作为 soft visual prompts 前置到文本 |
| 输出 | 自回归文本 | 保留 LLM 指令跟随能力 |

**关键设计**:
- Q-Former 是信息瓶颈：32×768 远小于图像特征，强制提取文本相关视觉信息。
- 第一阶段先学表示，第二阶段再学生成，减少 LLM 对齐负担与灾难性遗忘。
- 图像编码器与 LLM 都冻结，只训练 Q-Former（及投影层），参数量小、可快速换骨干。

## 实验的全部流程

### 数据准备
1. 129M 图像：COCO、VG、CC3M、CC12M、SBU、LAION400M 115M。
2. BLIP-large 为每图生成 10 条描述；CLIP ViT-L/14 打分，保留 top-2，训练时随机选一条。
3. 图像 224×224，随机缩放裁剪 + 水平翻转。

### 第一阶段：表示学习
4. 加载冻结 CLIP ViT-L/14 或 EVA-CLIP ViT-g/14，取倒数第二层特征。
5. Q-Former 用 32 个 query 通过 cross-attention 提取视觉特征，与文本通过 self-attention 交互。
6. 用不同 mask 分别计算 ITC（单模态）、ITG（多模态因果）、ITM（双向）；联合优化。
7. 250k steps，batch 2320/1680，AdamW，lr 1e-4，warmup 2k，cosine。

### 第二阶段：生成学习
8. 冻结第一阶段 Q-Former 与图像编码器，接冻结 LLM（OPT/FlanT5）。
9. FC 把 query 输出投影到 LLM 维度，前置为 soft visual prompts。
10. Decoder LLM 用 LM 损失；Encoder-decoder LLM 用 prefix LM 损失。
11. 80k steps，batch 1920/1520，最小 lr 5e-5。

### 下游评测
12. 零样本 VQA：VQAv2/OK-VQA/GQA，prompt `Question: {} Answer:`（OPT）或 `Short answer:`（FlanT5），beam 5，length penalty -1。
13. 图像描述：COCO 微调，NoCaps 零样本；冻结 LLM，更新 Q-Former + 图像编码器。
14. VQA 微调：冻结 LLM，更新 Q-Former + 图像编码器；问题输入 Q-Former。
15. 检索：不用 LLM，直接微调第一阶段模型，ITC/ITM/ITG；ITC 选 top-128，ITM 重排。
16. 消融：去掉第一阶段、ITG、问题引导等。

## 个人评价

**核心价值**: BLIP-2 把“冻结双塔 + 轻量连接”做到了极致：Q-Former 只有 188M，却能把任意视觉编码器接到任意 LLM 上，并在零样本 VQA 上超过 80B Flamingo。它的意义在于**把视觉-语言对齐从“重训练”变成“轻桥接”**，让视觉与语言社区的快速进步可以直接组合。这一思路直接影响了 InstructBLIP、MiniGPT-4、LLaVA 等模型。

**可借鉴点**:
- 对遥感/多模态：Q-Former 的 32 query 信息瓶颈适合把高分辨率、多尺度遥感特征压成固定 token，再接入 LLM；可显著降低显存与训练成本。
- **两阶段训练**很关键：先学“文本相关视觉表示”，再学“生成”，比直接端到端接 LLM 更稳，能缓解灾难性遗忘。
- **冻结骨干**使模型可以快速替换更强的视觉编码器/LLM；在领域数据有限时，优先冻结大模型、只训练连接器。
- **ITG 对检索也有帮助**：生成目标迫使 query 提取更完整的文本相关信息，说明理解与生成目标可以互补。
- **单图文对预训练不支持 in-context learning**：若要做少样本多图推理，需要交错图文数据（如 Flamingo M3W）；这对遥感多时相/多视角数据构造有启发。
- **参数效率口径要小心**：摘要 54×、表 2 的 108M vs 10.2B 是不同比较口径，引用时需说明。

**实验设计亮点**:
- 同时报告可训练参数、总参数、零样本/微调结果，参数效率一目了然。
- 系统比较 ViT-L/ViT-g、OPT/FlanT5、不同规模，证明框架可吸收单模态进步。
- 消融第一阶段、ITG、问题引导，解释每个组件的必要性。
- 零样本指令生成定性展示，说明冻结 LLM 的指令能力被保留。
- 诚实报告 OK-VQA 落后 Flamingo、缺少 in-context learning、生成可能受 LLM 知识限制。

## 疑问解答 (Q&A)

### Q1: Q-Former 的作用是什么？为什么不直接把图像特征拼给 LLM？

**答**：图像特征数量随分辨率变化，直接拼给 LLM 会使上下文过长、对齐负担大。Q-Former 用 32 个可学习 query 通过 cross-attention 提取固定 32×768 的表示，作为信息瓶颈：既压缩 token，又迫使 query 只保留与文本相关的信息。这样 LLM 只需处理少量 soft visual prompts，训练更高效。

### Q2: 两阶段预训练分别做什么？为什么不能只做第二阶段？

**答**：第一阶段用 ITC/ITG/ITM 让 Q-Former 学会提取语言相关视觉表示；第二阶段把这表示接入冻结 LLM，学生成。若只做第二阶段，Q-Former 只能靠生成损失盲目对齐，零样本 VQA 大幅下降，OPT 还会灾难性遗忘；第一阶段的表示学习显著降低 LLM 对齐负担。

### Q3: 为什么图像编码器和 LLM 都冻结？这样不会限制性能吗？

**答**：冻结是为了参数效率、避免灾难性遗忘、灵活复用现成模型。BLIP-2 只训练 Q-Former（188M）与投影层，却能超过 80B Flamingo 的零样本 VQA；说明只要连接器学好，冻结骨干足够强。冻结也让模型可以直接换更强的 ViT/LLM，而不用重训。

### Q4: ITC、ITG、ITM 的 attention mask 有什么区别？

**答**：
- ITC：单模态 mask，query 与文本不能互相看，只对齐各自表示；
- ITG：多模态因果 mask，query 之间可互相看但不能看文本，每个文本 token 可看所有 query 与其之前的文本；
- ITM：双向 mask，query 与文本完全互相看，学习细粒度匹配。
三种 mask 让同一套 Q-Former 参数完成对比、生成、匹配三种任务。

### Q5: 第二阶段对 decoder LLM 和 encoder-decoder LLM 分别用什么损失？

**答**：Decoder LLM（OPT）用语言建模损失，冻结 LLM 根据视觉 soft prompts 自回归生成文本；Encoder-decoder LLM（FlanT5）用 prefix 语言建模损失，把文本切成前缀/后缀，前缀与视觉表示拼接送入 encoder，后缀作为 decoder 生成目标。

### Q6: 为什么 BLIP-2 没有 in-context learning 能力？

**答**：预训练数据每条样本只有一个图文对，LLM 学不到“多个图文对在同一序列中如何关联”。因此即使给 LLM 提供 few-shot VQA 示例，也没有提升。Flamingo 使用交错图文数据 M3W 才有 few-shot 能力；BLIP-2 作者把构造类似数据列为未来工作。

### Q7: 摘要说“54 倍更少可训练参数”，Table 2 却是 108M vs 10.2B，怎么理解？

**答**：54× 是相对 Flamingo80B 的 **10.2B 可训练参数**（10.2B/188M≈54），用的是 Q-Former 总参数 188M；Table 2 的 108M 是特定配置（ViT-g + FlanT5-XXL）实际可训练参数，因为部分投影/配置不同。两个口径都来自论文，但比较对象不同，引用时需说明。

### Q8: BLIP-2 与 BLIP、Flamingo 的区别是什么？

**答**：
- BLIP：端到端 MED + CapFilt，统一理解/生成，但需训练整个模型；
- Flamingo：冻结视觉 + 冻结 LM，插入 cross-attention，支持交错图文与 few-shot，但连接层参数大（10.2B 可训练）；
- BLIP-2：冻结视觉 + 冻结 LLM，用轻量 Q-Former 两阶段桥接，参数效率最高，但不支持 in-context 多图学习。
三者代表“端到端统一”“冻结 LM + 重连接”“冻结双塔 + 轻连接”三条路线。
