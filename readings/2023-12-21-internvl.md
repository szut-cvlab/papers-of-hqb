## 摘要

**问题**: LLM 规模与能力快速增长，但视觉与视觉-语言基础模型的进展没有同步。现有 VLLM 常用轻量“胶水层”（Q-Former、线性投影）连接视觉编码器与 LLM，存在三个问题：
1. **参数规模不匹配**：LLM 可达千亿参数，视觉编码器通常只有十亿级，LLM 容量未被充分利用；
2. **表示不一致**：视觉模型多在纯视觉数据或 BERT 系文本上训练，与 LLM 的表示空间不一致；
3. **连接低效**：胶水层通常很轻且随机初始化，难以建模复杂跨模态交互。

**方案**: 提出 **InternVL**，把视觉基础模型扩展到 **6B** 参数（InternViT-6B），并用 **8B** 的语言中间件 **QLLaMA** 与 LLM 渐进对齐。核心设计：
1. **参数均衡的视觉/语言组件**：6B 视觉编码器 + 8B 语言中间件；
2. **一致表示**：用预训练多语言 LLaMA 初始化 QLLaMA，使视觉特征与 LLM 空间一致；
3. **渐进式图文对齐**：先在大规模噪声图文对上做对比学习，再在高质量细粒度数据上做生成学习，最后 SFT 接 LLM。

**关键创新/贡献**：
- **创新点1（6B 视觉编码器）**: InternViT-6B 在公开数据上取得强线性探测/分割结果，可替代 ViT-22B。
- **创新点2（QLLaMA 语言中间件）**: 8B、由多语言 LLaMA 初始化，新增 96 个可学习 query 与 1B cross-attention，既能做对比学习，也能做生成/连接 LLM。
- **创新点3（渐进对齐）**: 对比 → 生成 → SFT 三阶段，充分利用 6B 噪声数据与高质量细粒度数据。
- **创新点4（通用性）**: 同一套视觉组件可作为纯视觉 backbone、对比模型（InternVL-C）、生成模型（InternVL-G）、多模态对话（InternVL-Chat），覆盖 **32** 个视觉-语言 benchmark。

**验证**:
- ImageNet 线性探测 **88.2%**，ImageNet 变体平均 **82.5%**（Table 4）。
- ADE20K 分割：线性探测 **47.2 mIoU**（ViT-22B 34.6），全参数 **58.9**（ViT-22B 55.3）（Table 5）。
- 零样本图文检索：英文平均 **88.8**、中文平均 **90.9**（Table 7）。
- 零样本视频分类：8 帧 K400/K600/K700 平均 **79.4 / 78.8 / 71.5**（Table 8）。
- 多模态对话：InternVL-Chat（Vicuna-13B）MME **1317.2**、POPE **85.4**、VQAv2 **71.7**、GQA **59.5**、VizWiz **54.0**、TextVQA **49.1**（Table 9）。

## 1. 引言

**背景 & 动机**:
- LLM 的开放世界语言能力快速提升，VLLM（Qwen-VL、LLaVA、MiniGPT-4、Shikra、Kosmos-2、InstructBLIP、Flamingo、PaLI）也取得突破。
- 但视觉/视觉-语言基础模型的发展落后于 LLM，成为多模态 AGI 的瓶颈。
- 现有 VLLM 用轻量 glue 层连接视觉与语言，存在参数规模、表示一致性、连接效率三方面问题。

**本文思路**:
- 把视觉编码器提升到与 LLM 同一量级（6B），再用 8B 语言中间件对齐；不是简单加一个轻量投影，而是让视觉侧也有足够容量与语言对齐能力。
- 用渐进训练：先对比学习利用海量噪声数据，再生成学习利用高质量数据，最后 SFT 接 LLM。

**贡献**:
1. InternVL：首次把大规模视觉编码器与 LLM 对齐，覆盖感知、对比、生成、对话多类任务。
2. 渐进图文对齐策略：最大化利用 web-scale 噪声数据与高质量细粒度数据。
3. 在 32 个 benchmark 上系统比较，覆盖 ImageNet、ADE20K、Kinetics、Flickr30K/COCO 检索、MSR-VTT、COCO/Flickr30K/NoCaps 描述、MME/POPE/Tiny LVLM 对话。

## 2. 相关工作

### 2.1 视觉基础模型

- ResNet、Swin、InternImage 等视觉 backbone；CLIP/OpenCLIP/EVA-CLIP 等双塔视觉-语言模型。
- 视觉编码器规模从 ViT-L（0.3B）到 ViT-G（1.8B）、ViT-e（3.9B）、ViT-6.5B、ViT-22B。
- InternVL 的 InternViT-6B 目标是“公开数据上可替代 ViT-22B”的视觉基础模型。

### 2.2 大语言模型

- GPT-3、Chinchilla、LLaMA、Vicuna、InternLM 等；LLM 规模可达千亿。
- 多语言 LLaMA 为 QLLaMA 提供初始化，使视觉特征与 LLM 表示空间一致。

### 2.3 视觉大语言模型

- BLIP-2 用 Q-Former 连接冻结视觉与冻结 LLM；LLaVA 用线性投影 + 指令微调；Qwen-VL 用 adapter + 三阶段训练；Flamingo 用 gated cross-attention。
- 这些方法的 glue 层通常较轻，视觉编码器规模远小于 LLM。InternVL 的不同点是**把视觉侧也放大**，并用 8B QLLaMA 做中间件。

## 3. 方法

### 3.1 总体架构

InternVL 由两部分组成：
- **InternViT-6B**：6B 参数视觉 Transformer；
- **QLLaMA**：8B 参数语言中间件，由多语言 LLaMA 初始化，新增 96 个可学习 query 与 cross-attention（约 1B 参数）。

**灵活组合**:
1. **纯视觉 backbone**：InternViT-6B 直接做分类/分割/检测等感知任务。
2. **InternVL-C（对比）**：InternViT 或 InternViT+QLLaMA 编码图像，QLLaMA 的 `[EOS]` 编码文本，算相似度；用于零样本分类/检索。
3. **InternVL-G（生成）**：QLLaMA 的 query 重组织视觉表示，作为 prefix 文本，自回归生成描述。
4. **InternVL-Chat（对话）**：通过 MLP 接现成 LLM（Vicuna/InternLM），做多模态对话。

### 3.2 模型设计

**InternViT-6B**:
- 普通 ViT，规模扩到 6B。
- 超参搜索：深度 {32,48,64,80}、head dim {64,128}、MLP ratio {4,8}，共 16 个候选；最终选 width 3200、depth 48、MLP 12800、25 heads、5.9B 参数（Table 1）。
- 在 LAION-en 100M 子集上做对比学习，比较精度/速度/稳定性；深度/head dim/MLP ratio 对同参数模型精度影响不大，最终选最稳定配置。

**QLLaMA**:
- 基于预训练多语言 LLaMA，新增 96 个可学习 query 与 cross-attention 层（约 1B 参数，随机初始化）。
- 作用：
  1. 把 InternViT 的图像 token 转成与 LLM 对齐的表示；
  2. 8B 参数，比 Q-Former 大约 **42 倍**，即使冻结 LLM 也能有强对话能力；
  3. 可作为对比学习的强文本编码器。
- 与 BLIP-2 的 Q-Former、LLaVA 的线性层相比，QLLaMA 是“重型中间件”，目标是解决参数规模与表示一致性问题。

### 3.3 对齐策略

三阶段渐进训练：

**Stage 1：视觉-语言对比训练**
- InternViT-6B 随机初始化；文本编码器用多语言 LLaMA-7B 初始化；**全部参数可训练**。
- 数据：LAION-en、LAION-multi、LAION-COCO、COYO、Wukong 等；原始 **6.03B**，清洗后 **4.98B**（Table 2）。
- 目标：CLIP 对称交叉熵，对齐图像/文本特征。
- 产出：InternVL-C 的视觉编码器；该阶段视觉编码器也可直接用于分割等感知任务。

**Stage 2：视觉-语言生成训练**
- InternViT-6B 与 QLLaMA 继承 Stage 1 权重；新增 query/cross-attention 随机初始化。
- **冻结 InternViT 与 QLLaMA**，只训练新增的 query 与 cross-attention。
- 数据：从 4.98B 进一步过滤到 **1.03B** 高质量图文对（Table 2）。
- 目标：BLIP-2 的 ITC + ITM + ITG 三项损失。
- 产出：InternVL-G，具备零样本描述/检索能力，且特征空间与 LLM 对齐。

**Stage 3：监督微调（SFT）**
- 用 MLP 把 InternVL 接到现成 LLM（Vicuna/InternLM）。
- 数据：约 **4M** 高质量指令数据（Table 3）：Caption 588K、VQA 1.1M、OCR 294K、Grounding 323K、Grounded Caption 284K、Conversation 1.4M。
- 由于 QLLaMA 与 LLM 特征空间接近，可只训练 MLP，或训练 MLP+QLLaMA，冻结 LLM；既加速 SFT，又保留 LLM 语言能力。
- 产出：InternVL-Chat。

## 4. 实验

### 4.1 实现细节

- Stage 1：InternViT 随机初始化（BEiT 式），文本编码器用多语言 LLaMA-7B；全参数训练。
- Stage 2：冻结 InternViT 与 QLLaMA，只训练新增 query/cross-attention。
- Stage 3：两种配置——只用 InternViT，或用完整 InternVL；通过 MLP 接 LLM，SFT。
- 具体超参见附录；QLLaMA 用多语言 LLaMA 初始化，新增 96 queries + 1B cross-attn。

### 4.2 视觉感知

**ImageNet 线性探测**（Table 4）：

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| OpenCLIP-G | 1.8B | 86.2 | 89.4 | 77.2 | 63.8 | 87.8 | 66.4 | 78.5 |
| DINOv2-g | 1.1B | 86.5 | 89.6 | 78.4 | 75.9 | 78.8 | 62.5 | 78.6 |
| EVA-01-CLIP-g | 1.1B | 86.5 | 89.3 | 77.4 | 70.5 | 87.7 | 63.1 | 79.1 |
| MAWS-ViT-6.5B | 6.5B | 87.8 | — | — | — | — | — | — |

## 5. 结论

InternVL 把视觉基础模型扩展到 6B，并用 8B QLLaMA 渐进对齐，弥合视觉与 LLM 的规模/表示差距。它在图像/视频分类、检索、描述、VQA、多模态对话等 32 个 benchmark 上表现强，可作为通用视觉-语言基础模型。作者希望推动 VLLM 社区发展。

**局限**（论文未单列，设计与实验体现）:
- 6B 视觉编码器 + 8B QLLaMA 训练/推理成本高，部署门槛大；
- Stage 1 使用 4.98B 噪声图文对，数据清洗与训练稳定性要求高；
- 描述/对话仍可能出现幻觉，继承 LLM 与视觉编码器的偏见；
- 部分基准（如 TextVQA、VQAv2）不如专用/更强指令模型；
- 训练数据与完整流程部分依赖内部/公开混合数据，完全复现困难。

| 视觉编码器 | InternViT-6B，5.9B | width 3200、depth 48、MLP 12800、25 heads |
| 语言中间件 | QLLaMA，8B | 多语言 LLaMA 初始化；96 learnable queries + 1B cross-attn |
| 对比模式 | InternVL-C | InternViT 或 InternViT+QLLaMA 编码图像，QLLaMA `[EOS]` 编码文本 |
| 生成模式 | InternVL-G | QLLaMA query 作 prefix，自回归生成描述 |
| 对话模式 | InternVL-Chat | MLP 接 Vicuna/InternLM，SFT |
| 总规模 | 6B + 8B | 参数均衡的视觉/语言组件 |

**关键设计**:
- 视觉侧也放大到 6B，避免“LLM 很大、视觉很小”的容量失衡。
- QLLaMA 8B 比 Q-Former 大 42 倍，承担表示对齐与生成，而非轻量 glue。
- 三阶段：对比（噪声大数据）→ 生成（高质量数据）→ SFT（指令数据）。
- 冻结 LLM 也能有强对话能力，因为 QLLaMA 已把视觉特征对齐到 LLM 空间。

## 实验的全部流程

### 数据准备
1. Stage 1：收集 6.03B 图文对，清洗到 4.98B（LAION-en/multi、LAION-COCO、COYO、CC12M/3M、SBU、Wukong）。
2. Stage 2：进一步过滤到 1.03B 高质量图文对。
3. Stage 3：约 4M 指令数据（Caption/VQA/OCR/Grounding/Grounded Caption/Conversation）。

### 训练
4. Stage 1：InternViT-6B 随机初始化，文本编码器多语言 LLaMA-7B；全参数训练；CLIP 对称对比损失。
5. Stage 2：冻结 InternViT 与 QLLaMA，训练 96 queries + cross-attn；ITC+ITM+ITG。
6. Stage 3：MLP 接 Vicuna/InternLM；SFT 4M 数据；可冻结 LLM，只训 MLP 或 MLP+QLLaMA。
7. 视觉感知任务：InternViT-6B 直接做分类/分割 backbone。

### 评测
8. 视觉感知：ImageNet 线性探测 + 变体；ADE20K few-shot/线性/UperNet。
9. 零样本图像分类：ImageNet 变体、ObjectNet、多语 ImageNet。
10. 零样本视频分类：Kinetics-400/600/700，1/8 帧。
11. 零样本图文检索：Flickr30K/COCO 英文，Flickr30K-CN/COCO-CN 中文，XTD 多语。
12. 零样本图像描述：COCO/Flickr30K/NoCaps。
13. 多模态对话：MME、POPE、Tiny LVLM。
14. 消融：InternViT 超参、QLLaMA vs MLP、数据规模、LLM 规模。

## 个人评价

**核心价值**: InternVL 的核心判断是“视觉侧也要 scaling”：如果 LLM 有 70B，而视觉编码器只有 1B，轻量 glue 层很难让 LLM 充分发挥。它把视觉编码器做到 6B、语言中间件做到 8B，并用渐进对齐解决噪声数据与高质量数据的矛盾。这让我想到遥感/工业场景：如果领域视觉特征复杂（多光谱、高分辨率、小目标），仅靠轻量投影接 LLM 可能不够，需要更强的领域视觉编码器与中间件。

**可借鉴点**:
- **参数均衡**：视觉编码器与语言中间件的容量要匹配任务复杂度；遥感多光谱/高分辨率场景尤其如此。
- **QLLaMA 作为重型中间件**：8B、96 queries、1B cross-attn；比 Q-Former 更能保留细粒度信息，但也更贵。资源有限时可取中间规模。
- **渐进对齐**：先用海量噪声数据做对比，再用高质量数据做生成，最后 SFT；比直接端到端更稳，也更能利用不同质量的数据。
- **特征一致性**：用多语言 LLaMA 初始化 QLLaMA，使视觉特征与 LLM 空间一致；这比随机初始化的轻量投影更利于冻结 LLM 的对话。
- **一套视觉组件多用途**：纯视觉 backbone、对比、生成、对话共用 InternViT-6B；适合构建领域基础模型，避免为每个任务重训。
- **消融很有说服力**：同样只训 MLP，InternViT-6B 优于 EVA-E；换 QLLaMA 后大幅提升，说明“视觉规模 + 中间件规模”都重要。

**实验设计亮点**:
- 32 个 benchmark 覆盖感知、检索、描述、VQA、对话，评估面很广。
- 与 ViT-22B、EVA-CLIP、Qwen-VL、LLaVA-1.5、BLIP-2 等强基线对比，定位清晰。
- 同时报告线性探测、few-shot、全参数分割，验证视觉特征的通用性。
- 消融拆解视觉编码器、glue 层、LLM 规模、数据规模，结论有数据支撑。
- 诚实报告部分任务（TextVQA、VQAv2）不如专用模型。

## 疑问解答 (Q&A)

### Q1: 为什么要把视觉编码器做到 6B？轻量 glue 层不够吗？

**答**：论文指出三个问题：参数规模不匹配（LLM 千亿 vs 视觉十亿）、表示不一致（视觉模型与 LLM 空间不同）、连接低效（轻量随机初始化 glue 难以建模复杂交互）。把视觉编码器放大到 6B、用 8B QLLaMA 对齐，能让视觉侧也有足够容量，减少 LLM 的负担。消融显示同样只训 MLP，InternViT-6B 已优于 EVA-E；再加 QLLaMA 提升更大。

### Q2: QLLaMA 与 Q-Former 的区别是什么？

**答**：Q-Former 通常是轻量（188M）的 query transformer；QLLaMA 是 8B 的多语言 LLaMA，新增 96 个 query 与 1B cross-attention，规模约为 Q-Former 的 42 倍。它既能做对比学习的文本编码器，也能做生成中间件，还能把视觉特征对齐到 LLM 空间；因此即使冻结 LLM，也能有强对话能力。

### Q3: 三阶段训练分别做什么？为什么需要渐进？

**答**：
1. Stage 1：全参数训练 InternViT + 多语言 LLaMA 文本编码器，用 4.98B 噪声图文对做 CLIP 对比；
2. Stage 2：冻结视觉与 QLLaMA，只训新增 query/cross-attn，用 1.03B 高质量数据做 ITC/ITM/ITG；
3. Stage 3：接 LLM，用 4M 指令数据 SFT。
渐进策略先利用海量噪声数据学通用对齐，再用高质量数据学细粒度生成，最后指令微调；比直接端到端更稳、更充分利用数据。

### Q4: InternVL-C、InternVL-G、InternVL-Chat 有什么区别？

**答**：
- InternVL-C：对比模式，InternViT 或 InternViT+QLLaMA 编码图像，QLLaMA `[EOS]` 编码文本，算相似度；用于零样本分类/检索。
- InternVL-G：生成模式，QLLaMA 的 query 重组织视觉表示作为 prefix，自回归生成描述；用于零样本 captioning，也提升检索。
- InternVL-Chat：通过 MLP 接 Vicuna/InternLM，做多模态对话；可冻结 LLM，只训 MLP 或 MLP+QLLaMA。

### Q5: 96 个 learnable queries 的作用是什么？

**答**：QLLaMA 用 96 个 query 通过 cross-attention 从 InternViT 的视觉特征中提取信息，把变长视觉 token 压成固定数量的表示，并作为 LLM 的视觉 prefix。query 数量是容量与成本的折中；相比 BLIP-2 的 32 个 query，96 个更多，配合 8B QLLaMA 可保留更丰富的视觉信息。

### Q6: 为什么 Stage 2 只训练 query/cross-attention，冻结视觉与 QLLaMA？

**答**：Stage 1 已学到强视觉表示与语言对齐；Stage 2 的目标是让新增 query 学会从这些特征中提取文本相关信息，不需要破坏已学好的大模型。冻结可大幅降低训练成本、避免过拟合/灾难性遗忘，同时让 QLLaMA 的生成能力专注于重组视觉表示。

### Q7: InternVL 的视觉能力真的能替代 ViT-22B 吗？

**答**：在公开数据设定下，InternViT-6B 的 ImageNet 线性探测 88.2，接近使用私有 JFT-3B 的 ViT-22B（89.5），参数少 3.7 倍；ADE20K 分割所有设置均优于 ViT-22B（线性 47.2 vs 34.6，全参数 58.9 vs 55.3）。因此论文称“公开数据下可替代 ViT-22B”，但要注意 ViT-22B 用了更大的私有数据，比较并非完全同数据。

### Q8: InternVL 的局限是什么？

**答**：论文未单列局限，但从设计可见：
1. 6B+8B 参数量大，训练/推理成本高；
2. Stage 1 用 4.98B 噪声数据，清洗与稳定性要求高；
3. 描述/对话可能继承 LLM 与视觉编码器的幻觉/偏见；
4. 部分任务（TextVQA、VQAv2）不如专用/更强指令模型；
5. 完整训练数据与流程部分依赖内部/混合数据，复现门槛高。
